FullCalendar and Schedule-X render a finished calendar UI that you configure. calendar-tsx computes the layout and
gives you unstyled parts to render it, so you write more markup and own every pixel. Pick it when the calendar has
to match your design system, or when you want Temporal values end to end. Pick one of the others when a ready-made
calendar with a toolbar, popovers and modals is what you need. calendar-tsx is experimental: its API can change in any
release.

Checked against FullCalendar v7.1.3 and Schedule-X 4.9.1 on 2026-10-24. Both projects change; follow the linked
sources for current details.

✅ supported · 💎 paid plan · ❌ not supported · ❔ not documented

## Interactions

|                       | calendar-tsx                                  | FullCalendar                                                         | Schedule-X                                                |
| --------------------- | --------------------------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------- |
| Drag and drop, resize | ✅ Yes, opt-in features                       | ✅ Yes                                                               | 💎 Premium                                                |
| Range selection       | ✅ Yes                                        | ✅ Yes                                                               | 💎 Premium, the Draw plugin creates events by dragging    |
| Drag in from outside  | ✅ Yes, with relocation policies              | ✅ Yes, `Draggable`                                                  | 💎 Premium, drag to create                                |
| Between calendars     | ✅ Yes, event transfers                       | ✅ Yes, `eventLeave` and `eventReceive`                              | ❔ Not documented                                         |
| Touch                 | ✅ Hold to start, with auto-scroll            | ✅ Long press                                                        | ❔ Not documented                                         |

The calendar-tsx features report proposals and never change your events: you apply them. See
[selection and event editing](../features/interactions) and [external drops and transfers](../features/drops-and-transfers).

## Data and time

|                   | calendar-tsx                                                         | FullCalendar                                                                                                                 | Schedule-X                                              |
| ----------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| Time zones        | ✅ Any IANA zone; events are converted to it and laid out there      | ✅ `local`, `UTC` or an IANA zone; returned dates support only local and UTC ([docs](https://fullcalendar.io/docs/timeZone)) | ✅ IANA zone, `UTC` by default                          |
| Recurrence        | ✅ Daily and weekly in the core; full RRULE in `@calendar-tsx/rrule` | ✅ Simple built-in rules; `@fullcalendar/rrule` plugin                                                                       | ✅ Partial RRULE in `@schedule-x/event-recurrence`      |
| Background events | ✅ Yes, including timelines                                          | ✅ Yes                                                                                                                       | ✅ Yes, with RRULE                                      |
| Business hours    | ✅ Background layers, per resource, inverse or weekly                | ✅ `businessHours`, per resource                                                                                             | ❔ Not documented; `dayBoundaries` limits visible hours |
