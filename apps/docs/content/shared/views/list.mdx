An agenda: the days that have events, each with its events in order.

<CalendarPreview view='agenda' />

```ts
import { listView } from '@calendar-tsx/core';

listView({ days: 7 });
listView({ period: 'month' });
listView({ period: 'quarter' });
listView({ months: 3 });
listView({ weeks: 1, hiddenDays: [6, 7] });
```

Choose exactly one of `days`, `weeks`, `months`, or `period`. Counts must be positive integers.

| Duration    | Meaning                                                                |
| ----------- | ---------------------------------------------------------------------- |
| `days: N`   | N dates from `date`; `7` keeps its existing week alignment.            |
| `weeks: N`  | N whole weeks from `firstDayOfWeek`.                                   |
| `months: N` | N calendar months from the first day of the anchor month.              |
| `period`    | `'month'`, `'quarter'`, or `'year'`, aligned to its calendar boundary. |

`next()` and `prev()` advance the configured duration. Month-based steps land on the first day. `hiddenDays` omits ISO weekdays (`1` Monday to `7` Sunday) without changing the nominal period or its inclusive fetch range; at least one weekday must remain visible.

Only days with at least one event are listed, so a quiet range has no days; render an empty state for it.

`hiddenDays: [6, 7]` hides Saturday and Sunday using ISO weekdays (Monday `1`, Sunday `7`).

Hiding all seven weekdays is invalid. A controlled date with no visible weekdays produces an empty layout.
## Date headings

The supplied themes place the date beside its event rows. Give `ListViewDayHeader` a `<time dateTime={day.date.toString()}>` containing a `<strong>` day number and a `<span>` with the weekday and month/year. The React and Solid examples show this composition. The full date remains the heading's accessible name, and date formatting belongs to your application.

The date column narrows with the list, and its labels wrap when space is limited. Override `--calendar-list-date-width` (default `10rem`) to cap its width. `ListViewDay` emits `--cal-events` so the heading spans that day's event rows; render the header and events as direct children of the day.
