A month grid of whole weeks, with multi-day events as bars that span the days they cover.

<CalendarPreview view='month' />

```ts
import { monthView } from '@calendar-tsx/core';

monthView({ maxEventsPerDay: 3 });
```

## Settings

| Setting           | Type                                    | Description                                                                  |
| ----------------- | --------------------------------------- | ---------------------------------------------------------------------------- |
| `maxEventsPerDay` | `number`                                | Bar rows shown per week; bars in further rows are hidden and counted.        |
| `dayOverflow`     | `(date: Temporal.PlainDate) => boolean` | Marks a day as having more events, for example ones you have not loaded yet. |
| `fixedWeekCount`  | `boolean`                               | Always show six weeks, so the grid keeps its height from month to month.     |

The view shows the month containing `date`, padded to whole weeks that start on `firstDayOfWeek` (Sunday by default).
`next()` and `prev()` move by one month. See [overflow](../features/overflow) for the hidden rows.

## Model

`layout` is `{ kind: 'month', weekdays, weeks }`. `weekdays` holds the first week's seven dates, for column headers.

Each week holds `days`, its bar `segments`, its `backgroundEvents` and `rows`, the number of bar rows shown (at most
`maxEventsPerDay`). See [background events](../features/background-events).

| Day field     | Description                                                       |
| ------------- | ----------------------------------------------------------------- |
| `date`        | The day.                                                          |
| `isOutside`   | The day pads the grid and lies outside the month.                 |
| `isToday`     | The day is today in `timeZone`.                                   |
| `hiddenCount` | Hidden bar segments crossing this day.                            |
| `hasMore`     | `hiddenCount > 0`, or `dayOverflow` returned `true` for this day. |
| `events`      | Every event on this day, including hidden ones, in order.         |

| Bar segment field                   | Description                                                     |
| ----------------------------------- | --------------------------------------------------------------- |
| `event`                             | The event, in the calendar's time zone.                         |
| `colStart`, `colSpan`               | First column (zero-based) and the number of columns it covers.  |
| `row`                               | Zero-based row; each bar takes the lowest row free on its days. |
| `continuesBefore`, `continuesAfter` | The event extends past the week's first or last day.            |

## Parts

<section id='parts-table'>

| Part                           | Model prop                      | Element  | Notes                                                                                          |
| ------------------------------ | ------------------------------- | -------- | ---------------------------------------------------------------------------------------------- |
| `MonthView`                    | `model`: month layout           | `div`    | `role='grid'`.                                                                                 |
| `MonthViewHeader`              | none                            | `div`    | `role='row'`.                                                                                  |
| `MonthViewHeaderCell`          | `weekday`: `Temporal.PlainDate` | `div`    | `role='columnheader'`, `data-weekday`.                                                         |
| `MonthViewWeek`                | `week`                          | `div`    | `role='row'`. Holds the days and the week's bars.                                              |
| `MonthViewDay`                 | `day`                           | `div`    | `role='gridcell'`, `data-today`, `data-outside`.                                               |
| `MonthViewDayTrigger`          | `day`, `view`                   | `button` | Navigates to `view` on the day. See [day triggers](../features/day-triggers).                  |
| `MonthViewWeekEvent`           | `segment`                       | `button` | Positioned across the week's columns.                                                          |
| `MonthViewWeekBackgroundEvent` | `segment`                       | `div`    | `aria-hidden`. A [background event](../features/background-events); render it before the bars. |
| `MonthViewDayBackground`       | `background`                    | `div`    | `aria-hidden`. A [background layer](../features/background-layers)'s shading.                  |
| `MonthViewOverflow`            | `day`                           | `button` | Renders only when `day.hasMore`.                                                               |

Bars are children of the week, not of a day, because one bar can span several days.
