<section id='setup'>

Resources as rows on a horizontal time axis. Overlapping events in a row stack, and the row grows to fit them. An event
that crosses midnight is one bar.

<CalendarPreview view='timeline_week' />

```ts
import { timelineView } from '@calendar-tsx/core';

timelineView({ days: 7, groupBy: 'resource' }); // a week, one row per resource
timelineView({ days: 1, groupBy: 'resource', slotMinutes: 30 }); // a day
timelineView({ period: 'month', groupBy: 'resource', slotMinutes: 1440, minSlotWidth: '6rem' });
timelineView({ period: 'year', slotMinutes: 1440, minSlotWidth: '6rem' });
```

## Settings

<include>./common.mdx#durations</include>

| Setting           | Type                           | Default               | Description                                                          |
| ----------------- | ------------------------------ | --------------------- | -------------------------------------------------------------------- |
| `groupBy`         | `'resource'` or `['resource']` | none                  | One row per resource. Without it, the layout has one row.            |
| `slotMinutes`     | `number`                       | `60`                  | Positive integer slot length; the final slot may be shorter.         |
| `minSlotWidth`    | `string`                       | none                  | Passed through as the slot columns' minimum width, such as `'3rem'`. |
| `minEventMinutes` | `number`                       | half of `slotMinutes` | Minimum display duration, also used for stacking. `0` turns it off.  |
| `hiddenDays`      | ISO weekdays                   | none                  | See [hidden weekdays](#hidden-weekdays).                             |
| `timeWindow`      | `{ startMinutes, endMinutes }` | `[0, 1440)`           | See [visible hours](#visible-hours).                                 |

Set `minSlotWidth` on month and year timelines to keep daily columns readable; the supplied themes then scroll the
timeline horizontally.

- An event appears in every row whose resource it names.
- All-day events have no separate row. They stack with timed events, from the start of their first day to the start
  of the day after their last.
- A resource's [availability](resource-view) is shaded as in the resource view.
- [Background events](../features/background-events) shade the track without taking stack rows. Register
  `backgroundFeature` to add [background layers](../features/background-layers).

## Brief events

A brief timed event is displayed at least `minEventMinutes` long, half a slot by default, measured in visible clock
minutes across hidden dates and daylight-saving changes. With daily slots and `minSlotWidth: '6rem'`, a bar is then at
least `3rem` wide. Stacking uses the enlarged span, so neighboring brief events stay separately selectable. The event
keeps its real start and end for labels. Bars clip at the visible range's end, where one can be narrower than the
minimum. All-day events keep their date spans. Keep CSS padding and borders inside the computed width: a CSS-only
minimum would enlarge bars without restacking them.

## Model

`layout` is `{ kind: 'timeline', coordinates, slotUnits, slotMinutes, hourOffset, days, slots, rows, now, minSlotWidth }`.
Every `start` and `span` is a fraction of the concatenated visible windows. Dates keep equal widths across
daylight-saving transitions.

<include>./common.mdx#clock-axis</include>

- `days` holds one `{ key, date, isToday, colStart, colSpan, start, span }` per day, for the header. `colStart` and `colSpan` count
  slot columns.
- `slots` holds `{ key, date, time, dayOffset, col, start, span }` per slot. Fractional bounds give partial slots their actual width.
- `slotMinutes` is each slot's length, and `hourOffset` the slot units from each day's window start to its first hour.
- `rows` holds one row per resource, or a single row without `groupBy`.
- `now` is the current time's fraction of the visible scale, omitted on hidden dates and outside the range.

| Row field          | Description                                                      |
| ------------------ | ---------------------------------------------------------------- |
| `resource`         | The resource; absent without `groupBy`.                          |
| `segments`         | The row's events.                                                |
| `backgroundEvents` | Timed and all-day background-event coverage, without stack rows. |
| `backgrounds`      | Layer coverage, only with `backgroundFeature`.                   |
| `rows`             | Stack depth: how many events stack at the busiest point.         |
| `unavailable`      | Fractions of the range outside the resource's availability.      |
| `isUnavailable`    | The resource has no availability in the range.                   |

| Segment field                       | Description                                                        |
| ----------------------------------- | ------------------------------------------------------------------ |
| `event`                             | The event, in the calendar's time zone.                            |
| `start`, `span`                     | Display position and duration as fractions of the visible range.   |
| `fragments`                         | Exact coverage before clock enclosure and minimum sizing.          |
| `row`                               | Zero-based stack row; each event takes the lowest row free for it. |
| `isAllDay`                          | The event is all-day.                                              |
| `isMultiDay`                        | The event covers more than one date, before clipping.              |
| `continuesBefore`, `continuesAfter` | The event extends past the range.                                  |

Stacking follows [event order](../features/events#order). Display spans that only touch don't overlap.

Background events and layers are fractions of the track and take no stack rows. Timed shading clips to visible anchor
windows and can split at dates or DST gaps; all-day shading follows anchor dates, including their overnight portions.
Hidden weekdays get no shading. Layer ranges merge before inverse gaps are computed, and range callbacks receive
`inputRange`. In a resource timeline, unassigned background events shade every row, and assigned ones and
resource-limited layers shade only matching rows. An ungrouped timeline shows every background event.

## Parts

<section id='parts-table'>

| Part                          | Model prop                | Element  | Notes                                                                                             |
| ----------------------------- | ------------------------- | -------- | ------------------------------------------------------------------------------------------------- |
| `TimelineView`                | `model`                   | `div`    | `role='region'`, labelled "Timeline". Scrolls both ways. `--cal-slot-columns` sizes header slots. |
| `TimelineViewHeader`          | none                      | `div`    | Sticky; holds the day headers and the slot labels.                                                |
| `TimelineViewDayHeader`       | `day`                     | `div`    | `data-today`, `data-date`, `data-weekday`.                                                        |
| `TimelineViewDayTrigger`      | `calendar`, `day`, `view` | `button` | Navigates through `calendar` to `view` on the day. See [day triggers](../features/day-triggers).  |
| `TimelineViewSlotLabel`       | `slot`                    | `div`    | `slot` is the time slot, not the HTML attribute.                                                  |
| `TimelineViewBody`            | none                      | `div`    | Holds the rows and the now indicator.                                                             |
| `TimelineViewRow`             | `row`                     | `div`    | `data-unavailable`, `data-resource-id`.                                                           |
| `TimelineViewResource`        | `row`                     | `div`    | The resource cell; sticks to the start edge.                                                      |
| `TimelineViewLane`            | `row`                     | `div`    | Holds the row's unavailable time and events.                                                      |
| `TimelineViewUnavailable`     | `segment`                 | `div`    | `aria-hidden`.                                                                                    |
| `TimelineViewBackground`      | `background`              | `div`    | `aria-hidden`, `data-layer`, `data-kind`; render inside `TimelineViewLane`.                       |
| `TimelineViewBackgroundEvent` | `segment`                 | `div`    | `aria-hidden`, continuation flags; render inside `TimelineViewLane`.                              |
| `TimelineViewEvent`           | `segment`                 | `button` | `data-all-day`, `data-multi-day`, `data-continues-before`, `data-continues-after`.                |
| `TimelineViewNowIndicator`    | `model`                   | `div`    | `aria-hidden`. Renders only while now is inside the range.                                        |

The parts render no slot cells; themes draw the slot lines as a background of each lane.

With one slot per day, omit the slot-label row; the date header is enough. For subday slots, include minutes in the
labels. The examples put the full event dates and times in `title` and `aria-label`, so clipped bar text stays
available.
