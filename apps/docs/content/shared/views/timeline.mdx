<section id='setup'>

Resources as rows on a horizontal time axis. Overlapping events in a row stack, and the row grows to fit them. An event
that crosses midnight is one bar.

```ts
import { timelineView } from '@calendar-tsx/core';

timelineView({ days: 7, groupBy: 'resource' }); // a week, one row per resource
timelineView({ days: 1, groupBy: 'resource', slotMinutes: 30 }); // a day
timelineView({ period: 'month', groupBy: 'resource', slotMinutes: 1440, minSlotWidth: '6rem' });
timelineView({ period: 'year', slotMinutes: 1440, minSlotWidth: '6rem' });
```

## Settings

Choose exactly one of `days`, `weeks`, `months`, or `period`. Counts must be positive integers.

| Duration    | Meaning                                                                |
| ----------- | ---------------------------------------------------------------------- |
| `days: N`   | N dates from `date`; `7` keeps its existing week alignment.            |
| `weeks: N`  | N whole weeks from `firstDayOfWeek`.                                   |
| `months: N` | N calendar months from the first day of the anchor month.              |
| `period`    | `'month'`, `'quarter'`, or `'year'`, aligned to its calendar boundary. |

`next()` and `prev()` advance the configured duration. Month-based steps land on the first day. `hiddenDays` omits ISO weekdays (`1` Monday to `7` Sunday) without changing the nominal period or its inclusive fetch range; at least one weekday must remain visible.

| Setting           | Type                           | Default               | Description                                                          |
| ----------------- | ------------------------------ | --------------------- | -------------------------------------------------------------------- |
| `groupBy`         | `'resource'` or `['resource']` | none                  | One row per resource. Without it, the layout has one row.            |
| `slotMinutes`     | `number`                       | `60`                  | Positive integer slot length; the final slot may be shorter.                       |
| `minSlotWidth`    | `string`                       | none                  | Passed through as the slot columns' minimum width, such as `'3rem'`. |
| `minEventMinutes` | `number`                       | half of `slotMinutes` | Minimum display duration, also used for stacking. `0` turns it off.  |

Set `minSlotWidth` for month and year timelines to keep daily columns readable. With the supplied themes, the timeline scrolls horizontally when the columns exceed its width.

Brief timed events occupy at least half a slot by default. With daily slots and `minSlotWidth: '6rem'`, this gives a bar at least `3rem` wide on ordinary days. The core stacks using the enlarged display spans, so neighboring short events remain separately selectable. The event's actual start and end stay unchanged; use them for labels and event details. Display spans stop at the visible range's end, where a bar can be narrower than the minimum.

Set `minEventMinutes` to choose a different duration, or `0` for exact time widths. The minimum is measured in visible clock minutes, including across hidden dates and daylight-saving changes. It does not resize all-day events. Keep CSS inline padding and borders inside the calculated width; a CSS-only minimum would enlarge bars without restacking them.

- An event appears in every row whose resource it names.
- All-day events have no separate row. They stack with the timed events, from the start of their first day to the
  start of the day after their last.
- A resource's [availability](resource-view) is shaded as in the resource view.
- [Background events](../features/background-events) shade the track without taking stack rows.
  Register `backgroundFeature` to add [background layers](../features/background-layers).

`hiddenDays: [6, 7]` hides Saturday and Sunday using ISO weekdays (Monday `1`, Sunday `7`).

`timeWindow: { startMinutes: 480, endMinutes: 1080 }` shows 08:00–18:00. For 22:00–06:00 use
`{ startMinutes: 1320, endMinutes: 1800 }`; the following morning belongs to the starting date. Hiding Tuesday
still leaves Monday's Tuesday-morning portion visible. All-day items retain their calendar-date membership.

Bounds are integer clock minutes: `0 <= startMinutes < 1440` and
`startMinutes < endMinutes <= startMinutes + 1440`. Defaults are no hidden weekdays and `[0, 1440)`.
`slotMinutes` is a positive integer; a final partial slot keeps its actual size. Fetch events for navigation's
`inputRange`, which includes the following date when needed.

Hiding all seven weekdays is invalid. A controlled date with no visible weekdays produces an empty layout.

## Model

`layout` is `{ kind: 'timeline', coordinates, slotUnits, days, slots, rows, now, minSlotWidth }`. Every `start` and `span` is a **fraction of the
concatenated visible windows**. The default has 24 clock hours per displayed date. Dates keep equal
widths across daylight-saving transitions. Repeated hours share clock positions; visually overlapping events stack.

- `days` holds one `{ key, date, isToday, colStart, colSpan, start, span }` per day, for the header. `colStart` and `colSpan` count
  slot columns.
- `slots` holds `{ key, date, time, dayOffset, col, start, span }` per slot. Fractional bounds give partial slots their actual width.
- `rows` holds one row per resource, or a single row without `groupBy`.
- `now` is the current time's fraction of the visible scale, omitted on hidden dates and outside the range.

| Row field          | Description                                                      |
| ------------------ | ---------------------------------------------------------------- |
| `resource`         | The resource; absent without `groupBy`.                          |
| `segments`         | The row's events.                                                |
| `backgroundEvents` | Timed and all-day background-event coverage, without stack rows. |
| `backgrounds`      | Layer coverage, only with `backgroundFeature`.                   |
| `rows`             | Stack depth: how many events stack at the busiest point.         |
| `unavailable`      | Fractions of the range outside the resource's availability.      |
| `isUnavailable`    | The resource has no availability in the range.                   |

| Segment field                       | Description                                                        |
| ----------------------------------- | ------------------------------------------------------------------ |
| `event`                             | The event, in the calendar's time zone.                            |
| `start`, `span`                     | Display position and duration as fractions of the visible range.   |
| `row`                               | Zero-based stack row; each event takes the lowest row free for it. |
| `isAllDay`                          | The event is all-day.                                              |
| `continuesBefore`, `continuesAfter` | The event extends past the range.                                  |

Stacking follows [event order](../features/events#order). Display spans that only touch don't overlap.

Timed shading is clipped to visible anchor windows and can split at dates or DST gaps. All-day shading follows
anchor dates, including their overnight portions. Hidden weekdays contribute no shading. Layer ranges are merged
before inverse gaps are computed. Range callbacks receive `inputRange`, including any following morning.

Unassigned background events shade every resource; assigned ones shade their matching rows. An ungrouped timeline
includes all background events. Resource-limited layers apply only to matching resource rows.
