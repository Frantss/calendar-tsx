<section id='setup'>

Days as columns on a time axis, with timed events placed by time and overlapping events side by side. All-day events
sit in a row above.

```ts
import { timeGridView } from '@calendar-tsx/core';

timeGridView({ days: 7 }); // a week
timeGridView({ days: 1 }); // a day
```

## Settings

| Setting          | Type                               | Default            | Description                                                          |
| ---------------- | ---------------------------------- | ------------------ | -------------------------------------------------------------------- |
| `days`           | `number`                           | —                  | Days shown. `7` starts on `firstDayOfWeek`; others start on `date`.  |
| `allDay`         | `boolean`                          | `true`             | `false` drops the all-day row from the layout.                       |
| `slotMinutes`    | `number`                           | `30`               | Length of each time slot; should divide a day evenly.                |
| `minColumnWidth` | `string`                           | —                  | Passed through for horizontal scrolling, for example `'8rem'`.       |
| `groupBy`        | `'resource'`                       | —                  | One column per resource and day. See [resource view](resource-view). |
| `groupOrder`     | `'resource-first' \| 'date-first'` | `'resource-first'` | Column order when grouped.                                           |

`next()` and `prev()` move by `days` days.

## Model

`layout` is `{ kind: 'timeGrid', slots, columns, allDay, minColumnWidth }`.

- `slots` holds one `{ key, time }` per `slotMinutes` across the day, for axis labels.
- `columns` holds one column per day.
- `allDay` holds bar `segments` and `rows` for all-day events, with columns indexed like `columns`. It is absent when the
  view sets `allDay: false`.

Positions inside a column are **fractions of that day**, 0 at midnight and 1 at the next midnight, in real time: a
daylight-saving day is 23 or 25 hours long.

| Column field                               | Description                                                       |
| ------------------------------------------ | ----------------------------------------------------------------- |
| `date`                                     | The day.                                                          |
| `isToday`                                  | The day is today in `timeZone`.                                   |
| `segments`                                 | Timed events in this column.                                      |
| `now`                                      | Fraction of the day for the current time, only on today's column. |
| `resource`, `isUnavailable`, `unavailable` | See [resource view](resource-view).                               |

| Timed segment field                 | Description                                          |
| ----------------------------------- | ---------------------------------------------------- |
| `event`                             | The event, in the calendar's time zone.              |
| `start`, `span`                     | Fractions of the day.                                |
| `lane`, `lanes`                     | Its lane, and the lane count of its overlap cluster. |
| `continuesBefore`, `continuesAfter` | The event is clipped at midnight.                    |

Events that overlap, directly or through others, form a cluster. Each takes the lowest free lane, and every event in
the cluster shares the cluster's lane count. Events that only touch do not overlap.

## Parts

<section id='parts-table'>

| Part                        | Model prop       | Element  | Notes                                                         |
| --------------------------- | ---------------- | -------- | ------------------------------------------------------------- |
| `TimeGridView`              | `model`          | `div`    | `role='region'`, labelled "Time grid". Scrolls.               |
| `TimeGridViewHeader`        | —                | `div`    | Sticky column headers.                                        |
| `TimeGridViewColumnHeader`  | `column`         | `div`    | `data-today`, `data-unavailable`, `data-resource-id`.         |
| `TimeGridViewColumnTrigger` | `column`, `view` | `button` | Navigates to `view` on the column's date.                     |
| `TimeGridViewAllDay`        | —                | `div`    | Render it only when `allDay` is set.                          |
| `TimeGridViewAllDayEvent`   | `segment`        | `button` | A bar segment.                                                |
| `TimeGridViewBody`          | `model`          | `div`    | Holds the axis and the columns.                               |
| `TimeGridViewAxis`          | —                | `div`    | Optional.                                                     |
| `TimeGridViewAxisLabel`     | `slot`           | `div`    | `slot` is the time slot, not the HTML attribute.              |
| `TimeGridViewColumn`        | `column`         | `div`    | `data-today`, `data-unavailable`.                             |
| `TimeGridViewEvent`         | `segment`        | `button` | Placed by time and lane; `data-overlap` when it shares lanes. |
| `TimeGridViewNowIndicator`  | `column`         | `div`    | `aria-hidden`. Renders only in today's column.                |

Give the root a height, such as `max-block-size: 40rem`, to scroll inside the page instead of showing all 24 hours.
