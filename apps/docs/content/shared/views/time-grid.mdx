Days as columns on a time axis, with timed events placed by time and overlapping events side by side or cascaded.
All-day events sit in a row above.

<CalendarPreview view='week' />

```ts
import { timeGridView } from '@calendar-tsx/core';

timeGridView({ days: 7 }); // a week
timeGridView({ days: 1 }); // a day
timeGridView({ weeks: 1, hiddenDays: [6, 7] }); // a workweek
```

## Settings

<include>./common.mdx#durations</include>

| Setting             | Type                               | Default               | Description                                                          |
| ------------------- | ---------------------------------- | --------------------- | -------------------------------------------------------------------- |
| `allDay`            | `boolean`                          | `true`                | `false` drops the all-day row.                                       |
| `slotMinutes`       | `number`                           | `30`                  | Positive integer slot length; the final slot may be shorter.         |
| `minColumnWidth`    | `string`                           | none                  | Passed through for horizontal scrolling, for example `'8rem'`.       |
| `groupBy`           | `'resource'` or `['resource']`     | none                  | One column per resource and day. See [resource view](resource-view). |
| `groupOrder`        | `'resource-first' \| 'date-first'` | `'resource-first'`    | Column order when grouped.                                           |
| `overlap`           | `'side-by-side' \| 'cascade'`      | `'side-by-side'`      | How overlapping events share a column. See [overlap](#overlap).      |
| `minEventMinutes`   | `number`                           | half of `slotMinutes` | Shorter events are laid out this long. `0` turns it off.             |
| `shortEventMinutes` | `number`                           | `30`                  | Events laid out shorter than this are flagged `isShort`.             |
| `hiddenDays`        | ISO weekdays                       | none                  | See [hidden weekdays](#hidden-weekdays).                             |
| `timeWindow`        | `{ startMinutes, endMinutes }`     | `[0, 1440)`           | See [visible hours](#visible-hours).                                 |

## Overlap

Each overlapping event takes the lowest lane free at its start, then widens to the right until the next lane holding
an event it overlaps, or to the column's edge. `'side-by-side'` keeps events beside each other. `'cascade'` doubles
each event's width, up to the column's edge, so a later lane covers at most half of it; later lanes paint on top.

## Brief events

The core lays out an event shorter than `minEventMinutes` (half a slot by default) as that long, and gives it its own
lane if it would then cover the next event. The event keeps its real `end`, so label it from `segment.event`. Both
settings are minutes, measured on the displayed clock: half a slot is 24px with the default `3rem` slots and 16px with
`compact.css`, before the gap between events.

An event laid out shorter than `shortEventMinutes` gets `isShort` and `data-short`. The default theme puts its content
on one line, and hides the content of an event too short for one line.

## Model

`layout` is `{ kind: 'timeGrid', coordinates, slotUnits, slotMinutes, hourOffset, slots, columns, allDay, minColumnWidth }`.

- `slots` holds `{ key, time, dayOffset, start, span }` for axis labels, as fractions of the visible window.
- `slotMinutes` is each slot's length, and `hourOffset` the slot units from the window's start to its first hour (`0`
  on the hour). Themes draw hour lines from them.
- `columns` holds one column per day.
- `allDay` holds bar `segments`, `backgroundEvents` and `rows`, with columns indexed like `columns`. Its segments are
  the [day grid's bar segments](day-grid-view#model). It is absent when the view sets `allDay: false`.

Positions inside a column are fractions of its visible clock window.

<include>./common.mdx#clock-axis</include>

| Column field                               | Description                                                         |
| ------------------------------------------ | ------------------------------------------------------------------- |
| `date`                                     | The day.                                                            |
| `isToday`                                  | The day is today in `timeZone`.                                     |
| `segments`                                 | Timed events in this column.                                        |
| `lanes`                                    | The most lanes any overlap cluster in the column uses.              |
| `backgroundEvents`                         | See [background events](../guide/background-events).                |
| `now`                                      | Fraction of the window containing now, including overnight columns. |
| `resource`, `isUnavailable`, `unavailable` | See [resource view](resource-view).                                 |

| Timed segment field                 | Description                                                      |
| ----------------------------------- | ---------------------------------------------------------------- |
| `event`                             | The event, in the calendar's time zone.                          |
| `start`, `span`                     | Fractions of the visible window.                                 |
| `fragments`                         | Exact coverage before clock enclosure and minimum sizing.        |
| `lane`, `lanes`                     | Its lane, and the lane count of its overlap cluster.             |
| `inlineStart`, `inlineSize`         | Fractions of the column's width, after widening and any cascade. |
| `isShort`                           | Laid out shorter than `shortEventMinutes`.                       |
| `continuesBefore`, `continuesAfter` | The event is clipped at a window boundary.                       |

Events that overlap, directly or through others, form a cluster that shares one lane count. Events that only touch do
not overlap. Place events with `inlineStart` and `inlineSize`; `lane` and `lanes` remain for CSS written against them.
