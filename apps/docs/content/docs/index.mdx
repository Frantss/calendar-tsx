<Callout type='warn' title='Experimental'>
  calendar-tsx is an experiment. Its API can change or be removed in any release, without notice.
</Callout>

The core computes a render-ready view model — month grids with spanning bars, time grids with overlap lanes and
resource columns, lists — on [TanStack Store](https://tanstack.com/store) and
[Temporal](https://tc39.es/proposal-temporal/docs/). The React bindings render it as unstyled, composable parts.

## Packages

| Package                | Description                                          |
| ---------------------- | ---------------------------------------------------- |
| `@calendar-tsx/react`  | React bindings — hooks and parts.                    |
| `@calendar-tsx/core`   | Framework-agnostic calendar engine.                  |
| `@calendar-tsx/themes` | Stylesheets: a positioning base and a default theme. |
