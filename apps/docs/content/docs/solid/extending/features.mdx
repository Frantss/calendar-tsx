## Registering features

A view lists the features it takes part in. `createCalendarViews` collects them, and the calendar's `features` option
holds them all, together with calendar-wide features that no view lists. Registered features add their options to
`useCalendar`, their actions to `calendar.api` and their state to the selector's state:
