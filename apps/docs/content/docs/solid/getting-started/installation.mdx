---
title: Installation
description: Install the Solid bindings, the core and Temporal.
---

For SolidJS 2, follow the [SolidJS 2 guide](/docs/solid/getting-started/solid-2) for installation, compiler setup
and v2 imports. The setup below uses Solid 1.

```npm
npm i @calendar-tsx/solid @calendar-tsx/core temporal-polyfill
```

- Solid 1.x, from 1.8.
- `@calendar-tsx/core` holds the view factories (such as `dayGridView`) and the types; the Solid package builds on it.
- `temporal-polyfill` provides `Temporal`, which every date and time uses. Import `Temporal` from it until your
  runtimes ship it natively.

## Styles

The parts are unstyled. For a working look, add the themes package and import one theme:

```npm
npm i @calendar-tsx/themes
```

```ts
import '@calendar-tsx/themes/default.css';
```

See [themes](/docs/solid/styling/themes), or [Tailwind](/docs/solid/styling/tailwind) if your app uses it.
