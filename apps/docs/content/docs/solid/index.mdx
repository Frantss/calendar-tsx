---
title: Overview
description: Build calendars in Solid with headless, composable parts.
---

`@calendar-tsx/solid` creates a calendar from Solid signals and renders it with unstyled parts for month, week, day,
resource and list views. Part names, props, data attributes and `--cal-*` variables match the React bindings, so the
same themes style both.
