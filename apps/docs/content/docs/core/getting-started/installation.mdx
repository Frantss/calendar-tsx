---
title: Installation
description: Install the core and Temporal.
---

```npm
npm i @calendar-tsx/core temporal-polyfill
```

Every date and time the core accepts or returns is a [Temporal](https://tc39.es/proposal-temporal/docs/) value. Import
`Temporal` from `temporal-polyfill` until your runtimes ship it natively.

The core keeps its state in [TanStack Store](https://tanstack.com/store), which installs with it.

For styles, the [themes](/docs/core/styling/themes) work with any markup that renders the parts' attributes.
