## Attach browser elements

Core consumers render their own DOM. Register each measured track with a surface ref and attach source refs to
events and resize handles. The helper below shows one column and event; in a renderer, register the column once
and bind each of its events separately. Run the cleanup when replacing those elements.

<include lang='ts'>../../../../examples/core/interaction-host.ts#bindings</include>

Use `timeGridSurface()` for an all-day track, `timelineSurface(row.key)` for a timeline lane and
`dayGridSurface(section.key, row.key)` for a day-grid row. Measure the track without axis labels or gutters.

<include>../../../shared/features/interactions.mdx#preview</include>

Core consumers observe `calendar.api.interactions.store.state.preview` and subscribe to that store to redraw their
overlays. The [React example](/docs/react/features/interactions#render-the-draft) and
[Solid example](/docs/solid/features/interactions#render-the-draft) illustrate the same geometry.
