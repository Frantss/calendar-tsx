## Attach browser elements

You render the DOM yourself. Register each track with a surface ref, without axis labels or gutters, and attach source
refs to events and resize handles. The helper shows one column and one event; a renderer registers each column once
and binds each of its events. Run the cleanup when replacing those elements.

<include lang='ts'>../../../../examples/core/interaction-host.ts#bindings</include>

Other tracks use `timeGridSurface()` (all-day), `timelineSurface(row.key)` and `dayGridSurface(section.key, row.key)`.
