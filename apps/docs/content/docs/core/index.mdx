---
title: Overview
description: The framework-agnostic calendar engine.
---

`@calendar-tsx/core` turns a view, a date and a list of events into a render-ready model: day grids with spanning
bars, time grids with overlap lanes and resource columns, lists and resource timelines. It owns no DOM and no styles.
Use it from plain TypeScript, from a framework without bindings, or to write bindings of your own. For React or
Solid, start with their bindings, which use this package for you.
