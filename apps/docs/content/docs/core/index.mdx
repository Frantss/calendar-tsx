---
title: Overview
description: The framework-agnostic calendar engine.
---

`@calendar-tsx/core` turns a view, a date and a list of events into a render-ready model: month grids with spanning
bars, time grids with overlap lanes and resource columns, and day lists. It owns no DOM and no styles. Use it directly
from plain TypeScript or a framework without bindings, or to write bindings of your own.

If you use React or Solid, start with their bindings instead; they use this package for you.
