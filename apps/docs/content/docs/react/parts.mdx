---
title: Parts
description: The month, time-grid and list parts, their props and how they nest.
---

Every part renders one element with `data-scope='calendar'`, a `data-part` name, state attributes and its geometry as
`--cal-*` custom properties. The [custom themes reference](/docs/themes/custom-themes#parts) lists each part's
attributes and variables.

Parts take their model from the layout and render your children. They accept any props of their element, plus
[`render`](/docs/react/rendering-parts).

## Month

```tsx
<MonthView model={layout}>
  <MonthViewHeader>
    {layout.weekdays.map(weekday => (
      <MonthViewHeaderCell key={weekday.toString()} weekday={weekday}>
        {weekday.toLocaleString('en-US', { weekday: 'short' })}
      </MonthViewHeaderCell>
    ))}
  </MonthViewHeader>
  {layout.weeks.map(week => (
    <MonthViewWeek key={week.key} week={week}>
      {week.days.map(day => (
        <MonthViewDay key={day.key} day={day}>
          <MonthViewDayTrigger day={day} view='day'>
            {day.date.day}
          </MonthViewDayTrigger>
          <MonthViewOverflow day={day} onClick={() => openDay(day)}>
            {day.hiddenCount} more
          </MonthViewOverflow>
        </MonthViewDay>
      ))}
      {week.segments.map(segment => (
        <MonthViewWeekEvent key={segment.key} segment={segment}>
          {segment.event.data.title}
        </MonthViewWeekEvent>
      ))}
    </MonthViewWeek>
  ))}
</MonthView>
```

| Part                  | Model prop                      | Element  | Notes                                                  |
| --------------------- | ------------------------------- | -------- | ------------------------------------------------------ |
| `MonthView`           | `model`: month layout           | `div`    | `role='grid'`.                                         |
| `MonthViewHeader`     | —                               | `div`    | `role='row'`.                                          |
| `MonthViewHeaderCell` | `weekday`: `Temporal.PlainDate` | `div`    | `role='columnheader'`.                                 |
| `MonthViewWeek`       | `week`                          | `div`    | `role='row'`. Holds the days and the week's bars.      |
| `MonthViewDay`        | `day`                           | `div`    | `role='gridcell'`.                                     |
| `MonthViewDayTrigger` | `day`, `view`                   | `button` | Navigates to `view` on the day.                        |
| `MonthViewWeekEvent`  | `segment`: bar segment          | `button` | Positioned across the week's columns.                  |
| `MonthViewOverflow`   | `day`                           | `button` | Renders only when `day.hasMore`. You handle the click. |

`MonthViewWeekEvent` bars are siblings of the days inside the week, not children of a day: one bar can span several
days.

## Time grid

```tsx
<TimeGridView model={grid}>
  <TimeGridViewHeader>
    {grid.columns.map(column => (
      <TimeGridViewColumnHeader key={column.key} column={column}>
        <TimeGridViewColumnTrigger column={column} view='day'>
          {column.resource?.title ?? column.date.toLocaleString('en-US', { weekday: 'short', day: 'numeric' })}
        </TimeGridViewColumnTrigger>
      </TimeGridViewColumnHeader>
    ))}
  </TimeGridViewHeader>
  {grid.allDay && (
    <TimeGridViewAllDay>
      {grid.allDay.segments.map(segment => (
        <TimeGridViewAllDayEvent key={segment.key} segment={segment}>
          {segment.event.data.title}
        </TimeGridViewAllDayEvent>
      ))}
    </TimeGridViewAllDay>
  )}
  <TimeGridViewBody model={grid}>
    <TimeGridViewAxis>
      {grid.slots.map(slot => (
        <TimeGridViewAxisLabel key={slot.key} slot={slot}>
          {slot.time.toLocaleString('en-US', { hour: 'numeric', minute: '2-digit' })}
        </TimeGridViewAxisLabel>
      ))}
    </TimeGridViewAxis>
    {grid.columns.map(column => (
      <TimeGridViewColumn key={column.key} column={column}>
        {column.unavailable.map(segment => (
          <TimeGridViewUnavailable key={segment.key} segment={segment} />
        ))}
        {column.segments.map(segment => (
          <TimeGridViewEvent key={segment.key} segment={segment}>
            {segment.event.data.title}
          </TimeGridViewEvent>
        ))}
        <TimeGridViewNowIndicator column={column} />
      </TimeGridViewColumn>
    ))}
  </TimeGridViewBody>
</TimeGridView>
```

| Part                        | Model prop                     | Element  | Notes                                                           |
| --------------------------- | ------------------------------ | -------- | --------------------------------------------------------------- |
| `TimeGridView`              | `model`: time-grid layout      | `div`    | `role='region'`, labelled "Time grid".                          |
| `TimeGridViewHeader`        | —                              | `div`    | Column headers.                                                 |
| `TimeGridViewColumnHeader`  | `column`                       | `div`    |                                                                 |
| `TimeGridViewColumnTrigger` | `column`, `view`               | `button` | Navigates to `view` on the column's date.                       |
| `TimeGridViewAllDay`        | —                              | `div`    | Only when `grid.allDay` is set.                                 |
| `TimeGridViewAllDayEvent`   | `segment`: bar segment         | `button` |                                                                 |
| `TimeGridViewBody`          | `model`                        | `div`    | Holds the axis and the columns.                                 |
| `TimeGridViewAxis`          | —                              | `div`    | Optional.                                                       |
| `TimeGridViewAxisLabel`     | `slot`                         | `div`    | `slot` is the time slot, not the HTML attribute.                |
| `TimeGridViewColumn`        | `column`                       | `div`    |                                                                 |
| `TimeGridViewUnavailable`   | `segment`: unavailable segment | `div`    | `aria-hidden`. Shades time outside the resource's availability. |
| `TimeGridViewEvent`         | `segment`: timed segment       | `button` | Positioned by time and lane.                                    |
| `TimeGridViewNowIndicator`  | `column`                       | `div`    | `aria-hidden`. Renders only in today's column.                  |

## List

```tsx
<ListView model={list}>
  {list.days.map(day => (
    <ListViewDay key={day.key} day={day}>
      <ListViewDayHeader day={day}>{day.date.toLocaleString('en-US', { dateStyle: 'full' })}</ListViewDayHeader>
      {day.events.map(event => (
        <ListViewEvent key={event.id} event={event}>
          {event.data.title}
        </ListViewEvent>
      ))}
    </ListViewDay>
  ))}
  <ListViewEmpty>No events</ListViewEmpty>
</ListView>
```

| Part                | Model prop           | Element   | Notes                                   |
| ------------------- | -------------------- | --------- | --------------------------------------- |
| `ListView`          | `model`: list layout | `div`     | `role='region'`, labelled "Event list". |
| `ListViewDay`       | `day`                | `section` |                                         |
| `ListViewDayHeader` | `day`                | `h3`      |                                         |
| `ListViewEvent`     | `event`              | `button`  |                                         |
| `ListViewEmpty`     | —                    | `div`     | Renders only when the list has no days. |

## Triggers

`MonthViewDayTrigger` and `TimeGridViewColumnTrigger` take a `view` key and navigate to that view on their date when
clicked, through `onNavigate`. Your own `onClick` runs first; call `event.preventDefault()` in it to skip the
navigation.

Their default accessible name is "Go to" followed by the full date, formatted in the provider's `locale`. Pass
`aria-label` to replace it.

## Events and overflow

Event parts and the overflow trigger render native buttons with no behavior. Attach `onClick` to open a drawer,
popover or details page; the calendar has no built-in popover.
