## Now indicator

Render `TimeGridViewNowIndicator` in every column; it renders only in today's column, at `column.now`. See the
[week and day view](/docs/react/views/week-and-day-view#example).

In timelines, render one `TimelineViewNowIndicator` with the layout as `model`; it renders only while now is in
the visible range.
