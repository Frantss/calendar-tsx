---
title: Overview
description: Build calendars in React with headless, composable parts.
---

`@calendar-tsx/react` creates a calendar from React state and renders it with unstyled parts for month, week, day,
resource and list views. The parts emit their layout as data attributes and CSS custom properties, so you style them
with a theme or your own CSS.
