# @calendar-tsx/react

> [!WARNING]
> **Experimental.** The API can change or be removed in any release, without notice.

React 18/19 bindings for [`@calendar-tsx/core`](../core): `useCalendar`, `CalendarProvider` and unstyled,
composable parts for the day-grid, time-grid, list and timeline layouts.

```bash
npm i @calendar-tsx/react @calendar-tsx/core temporal-polyfill
```

Parts carry no styles; add [`@calendar-tsx/themes`](../themes) for a working look.

See the [documentation](../../apps/docs/content/docs/react), starting with the [quick start](../../apps/docs/content/docs/react/getting-started/quick-start.mdx).
