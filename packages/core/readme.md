# @calendar-tsx/core

> [!WARNING]
> **Experimental.** The API can change or be removed in any release, without notice.

Headless, framework-agnostic calendar engine on TanStack Store and Temporal. It derives day-grid, time-grid,
list and timeline view models from controlled view and date options and event input, in one time zone, with
opt-in features for backgrounds, recurrence and interactions.

```bash
npm i @calendar-tsx/core temporal-polyfill
```

Use it through [`@calendar-tsx/react`](../react) or [`@calendar-tsx/solid`](../solid), or render the model yourself.

See the [documentation](../../apps/docs/content/docs/core), starting with the [quick start](../../apps/docs/content/docs/core/getting-started/quick-start.mdx).
